# QA Automation Engineer Assessment

## 📂 Project Structure
```
/ui-tests        -> UI Automation (SauceDemo)
/api-tests       -> API Automation (JSONPlaceholder)
/unit-tests      -> Unit Tests
/e2e             -> End-to-End Flow
```

## ⚙️ Setup
```bash
pip install -r requirements.txt
```

## ▶️ Run Tests
```bash
pytest ui-tests/
pytest api-tests/
pytest unit-tests/
pytest e2e/
```
